HAL-482 Duplicate ledger entries on retry

In Progress · Priority: Urgent · Assignee: Kofi Mensah · Project: Ledger reliability

Description

When a client retries POST /v1/transfers with the same Idempotency-Key, we insert a second ledger entry. Repro on local:

curl -s -X POST http://localhost:8080/v1/transfers \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: 7f2c9a10-2b1e-4c55-9d0e-a1b2c3d4e5f6' \
  -d '{"from":"acct_1042","to":"acct_2217","amount_cents":12500,"currency":"USD"}'
